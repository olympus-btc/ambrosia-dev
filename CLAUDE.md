## Commands

```bash
npm start          # Start dev server with live reload (default locale: Spanish)
npm run build      # Build static site to /build
npm run serve      # Serve the built static files locally
npm run clear      # Clear Docusaurus cache (use when seeing stale content)
npm run deploy     # Deploy to GitHub Pages
npm run write-translations  # Extract i18n strings for translation
npm run write-heading-ids   # Generate explicit heading IDs in markdown files
```

Requires Node.js >= 18. There is no test runner configured in this project.

## Architecture

**Docusaurus 3** static site — the developer documentation portal for Ambrosia-POS, a Bitcoin Point-of-Sale system. Deployed to GitHub Pages via `.github/workflows/deployment.yml` on pushes to `main`.

**Localization:** Spanish (`es`) is the **default locale**. English (`en`) translations live in `/i18n/en/`. All new user-facing strings must be added to both locales.

i18n workflow:
1. For markdown content: add the Spanish file to `/docs/` (or `/blog/`, `/team/`) and mirror it under `/i18n/en/docusaurus-plugin-content-*/current/`
2. For React component strings: wrap text with `<Translate id="key.path">Default Spanish text</Translate>` (import from `@docusaurus/Translate`), then run `npm run write-translations` to populate `/i18n/en/code.json`
3. Fill in the English values in `code.json`
4. Run `./find_unused_translations.sh` to detect stale keys

**Styling:** Tailwind CSS (Preflight disabled — Docusaurus handles resets) + Infima (Docusaurus's built-in CSS framework). Custom Ambrosia green palette defined as CSS variables in `src/css/custom.css` and referenced in `tailwind.config.js`. Dark mode uses `[data-theme="dark"]` selector (not `.dark` class).

**Sidebars** (`sidebars.js`): Two sidebars — `apiSidebar` (API Reference + Developer Portal) and `phoenixSidebar` (Lightning Network docs). Both use autogenerated structure from the `/docs/` directory.

## Key Directories

- `src/components/` — Homepage React components (Hero, Features, Benefits, TechStack, ContributorCTA)
- `src/pages/index.js` — Homepage that composes all homepage sections
- `docs/API/` — API reference organized by domain: Authentication, Billing, Bitcoin, Configuration, Inventory, Printing, Restaurant
- `docs/Development/` — Developer setup guides
- `docs/Phoenixd/` — Lightning Network (phoenixd) integration docs
- `blog/` — Blog posts; `authors.yml` and `tags.yml` define metadata
- `team/` — Team member profiles (separate Docusaurus blog plugin instance)
- `i18n/en/` — English translation overrides
- `static/` — Static assets served as-is

## Search

Powered by `@easyops-cn/docusaurus-search-local` (registered under `themes` in `docusaurus.config.js`). The index is built at `npm run build` time — **search does not work with `npm start`**. To test search locally, use `npm run build && npm run serve`.

Styling overrides (input, Ctrl+K badges, results dropdown) are at the bottom of `src/css/custom.css`.

- Code highlighting: Oceanic Next (light) / Dracula (dark)
